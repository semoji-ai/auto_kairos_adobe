## 어미 체계 (가장 중요)
- 기본 존댓말: **"~습니다 / ~입니다"**. 팩트 전달은 반드시 이 어미.
- 구어체 혼용: 공감·환기 지점에서 **"~거죠 / ~잖아요 / ~거든요"**.
- 전달체: 간접 사실은 **"~다고 합니다 / ~했다고 합니다"** — 3인칭 전달체로 이야기 듣는 느낌 유지.
- **평서체("~했다 / ~됐다 / ~이다") 금지.** 한 문장도 쓰지 않는다.

## 리듬
- 숫자·팩트 → **짧은 문장 2~3연타** → 의미 부여 문장 1개.
- **"그런데" 단독 행 반전**: 흐름을 끊고 새 방향 제시(집중도 리셋). 원고당 1회 이상.
- **"하지만" 역전**: 긍정 서술 → "하지만" → 장애물 → 극복. 반복 사용.
- 핵심 순간엔 인물 대사 **직접 인용** (따옴표).
- 강조어: 핵심 등장 직전 "바로", 숫자 강조 "무려", 클라이맥스 "그야말로",
  의미 부여 "이것은 단순한 ~이 아니었습니다".

## 구조
- 도입부 30초 이내(3~5문장): 시사연결 / 뉴스팩트충격 / 질문던지기 중 택1
  → "그런데" 또는 질문으로 전환 → **`(타이틀)` 마커 1회 삽입** → 본론.
- 챕터: **번호 + 제목** (`1. 어린 시절`). 인물·브랜드 5~7개, 지식 1~3개, 역사 3~5개.
- 1문단 = 2~5문장, 문단 사이 빈 줄(나레이션 호흡). 핵심 문장은 단독 행.
- 1문장 = 나레이션 1호흡. 긴 문장은 줄바꿈으로 분리.

## 표기
- 숫자는 **아라비아 숫자**로 표기(1954년, 4,040톤). 한글 숫자 표기 금지.
- 일본어 가나·한자 금지. 외래어는 한글 표기 또는 영어.
