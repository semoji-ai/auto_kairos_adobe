# scene-image

씬 이미지는 텍스트 프롬프트만으로도, 이미지만으로도 생성하지 않는다. **4가지를 모두 조합**해 통제 생성한다.

## 프롬프트 4요소 (v4 `scripts/generate_images_codex.py` build_full_prompt 구조 준용)
1. **아트스타일 텍스트 프롬프트** — `data/artstyle/semoji.md` 전문 + 핵심 요구사항 체크리스트. **반드시 포함**(이미지 전체에 적용되는 그림체 규칙).
2. **레퍼런스 이미지** — codex `-i`로 첨부. 첨부 순서 고정:
   - ① 스토리보드 콘티(`storyboard/sb_N.png`) — 구도/앵글/포즈
   - ② 기준 캐릭터 시트(char_ref) — 인물 외형
3. **장면 프롬프트** — 만들려는 씬 설명: 제목, 내레이션 맥락, 등장 인물(cast), 핵심 사물/장소.
4. **라벨링 explainer** — 첨부 이미지가 각각 무엇이고 어떻게 쓰는지 + 아트스타일 텍스트의 의미를 codex에 명시. **이게 핵심**(없으면 콘티의 거친 인물에 끌려 인물이 망가짐 — 실증).

## explainer 필수 문구 (의미 고정)
- "첫 번째 첨부 이미지는 **스토리보드 콘티**다 — **구도·카메라 앵글·포즈만 참고**하고, 콘티의 인물 그림체·선·질감은 절대 따르지 말 것."
- "두 번째 첨부 이미지는 **기준 캐릭터 시트**다 — **얼굴·머리·의상·비율을 정확히 일치**시키고 동일 인물로 유지(재설계 금지)."
- "위 아트스타일 설명은 **이미지 전체**(인물·배경·소품·액자 속 그림·화면 포함)에 적용되는 그림체다 — 사실적 사진/3D/페인터리 혼입 금지."

## 프롬프트 조립 순서
아트스타일(1) → 장면(3) → explainer(4) → 구도/비율/노텍스트 규칙
(이미지(2)는 CLI `-i`로 첨부)

## 호출 형태
```bash
printf '%s' "$ARTSTYLE_TEXT

$SCENE_PROMPT

$EXPLAINER

aspect ratio 16:9. 글자/말풍선/로고 없음. 인물 비율 일관." \
  | codex exec --skip-git-repo-check -s workspace-write \
      -i <storyboard/sb_N.png> -i <char_ref.png> -
```

## 파이프라인 위치
원고 → 씬별 콘티(storyboard) + 기준 캐릭터(M3e) → **scene-image(아트스타일+콘티+캐릭터+장면→씬)** → 씬 레이어 분리 → AE

## 용어 정리 (중복 해소)
- **스토리보드(콘티)** = 흑백 스케치, 구도/샷 설계 (Seedance 비디오 소스로도 사용)
- **기준 캐릭터** = 인물 외형 단일 소스
- **아트스타일 텍스트** = 그림체 단일 소스(`semoji.md`)
- **씬 이미지** = 위 요소로 생성된 결과 (영상/AE용)
- **에셋 이미지** = 씬에서 분리한 요소 레이어
