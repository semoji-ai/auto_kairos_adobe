# scene-image

씬 이미지는 **텍스트 프롬프트로 막 생성하지 않는다.** 반드시 아래 2개 이미지를 codex에 첨부해 통제 생성한다.

## 입력 (codex `-i` 첨부 순서 고정)
1. **스토리보드 콘티** (`sb_sketch` / storyboard/sb_N.png) — **장면 연출과 카메라 앵글만** 참고
2. **기준 캐릭터 레퍼런스** (char_ref) — **이 인물을 구도에 배치**하고, **반드시 이 이미지의 그림 스타일(선·색·질감·비율) 그대로** 그린다

## 핵심 규칙
- **스타일의 단일 소스 = 기준 캐릭터 레퍼런스 이미지.** 아트스타일 텍스트 프롬프트(semoji.md 등)를 직접 주입하지 말 것.
  - 실증: 텍스트 스타일을 함께 주입하면 콘티의 거친 인물 스케치에 끌려 **인물이 망가지고 char_ref 외형을 잃는다.** 이미지로만 스타일을 받으면 인물·품질이 유지됨.
- 콘티는 **구도/앵글 컨트롤러**일 뿐 — 인물·스타일은 콘티에서 가져오지 않는다.
- 텍스트(글자)가 들어간 이미지 요구 금지.

## 호출 형태
```bash
printf '%s' "첫 번째 이미지(스토리보드)는 장면 연출과 카메라 앵글만 참고한다. \
두 번째 이미지(캐릭터 레퍼런스)의 인물을 그 구도에 배치하고, 반드시 두 번째 이미지의 \
그림 스타일(선·색·질감·비율) 그대로 그린다. image_gen으로 ./scene.png 저장. 텍스트 없음." \
  | codex exec --skip-git-repo-check -s workspace-write \
      -i <sb_sketch.png> -i <char_ref.png> - 
```

## 파이프라인 위치
원고 → 씬별 콘티(storyboard) + 기준 캐릭터(M3e) → **scene-image(콘티+캐릭터→씬)** → 씬 레이어 분리 → AE

## 용어 정리 (중복 해소)
- **스토리보드(콘티)** = 흑백 스케치, 구도/샷 설계 (Seedance 비디오 소스로도 사용)
- **기준 캐릭터** = 인물 외형·스타일 단일 소스
- **씬 이미지** = 위 둘로 생성된 결과 (영상/AE용)
- **에셋 이미지** = 씬에서 분리한 요소 레이어

## 한국어 규칙
