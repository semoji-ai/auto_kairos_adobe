# character-sheet

캐릭터 시트는 이후 씬 생성의 **인물·스타일 단일 소스**다. **생성 시점부터 아트스타일 텍스트를 주입**해 처음부터 semoji 그림체로 태어나게 한다 — 씬 단계에서 스타일을 덧입히는 방식이 아니다.

## 프롬프트 구성 (v4 `scripts/generate_character_sheets.py` build_sheet_prompt 준용)
1. **아트스타일 텍스트** — `data/artstyle/semoji.md` 전문 + 핵심 요구사항. **첫머리에 강하게**(ART STYLE — must follow strictly).
2. **캐릭터 정체성** — 이름 / kind(real_person·가상 등) / 한국어 묘사 / 영문 묘사 / notes.
3. **시트 구도** — 단일 인물, 전신, 정면, 중립 표정, 플랫 단색 배경. semoji 3~3.5등신 비율(큰 머리·통통 몸통·짧은 다리)이 다 보이게. 다운스트림 재사용을 위한 **깨끗한 격리 피사체**.
4. **스타일 락(critical)** — semoji 핵심(보더리스·플랫·점눈·뮤트 팔레트) 재강조 + "여러 씬에 재등장하므로 디자인은 **기억에 남고 식별 가능**해야 함".
5. **출력 규칙** — 플랫 단색 배경(off-white/sage/beige), 글자·로고·말풍선 없음, 군중·배경 요소 없는 격리 캐릭터.

## 스타일 레퍼런스 이미지 — **필수**
- `data/artstyle/semoji_base.jpg`를 `-i`로 **반드시 첨부**한다. 텍스트만으로는 비율이 chibi로 드리프트함(실증: 텍스트만 → 4등신 chibi / 베이스 첨부 → ~5등신 베이스 일치).
- explainer 필수: "이 첨부 이미지는 세모지 베이스 스타일 레퍼런스다 — **그림체(선·색·셰이딩)와 신체 비율·얼굴 구조(코·턱 포함)를 정확히 매칭**할 것. 단, 인물 정체성(얼굴·헤어·의상)은 복사하지 말고 묘사대로 새 인물을 생성."
- 베이스 = 스타일·비율의 **그라운드 트루스**. 텍스트(semoji.md)와 충돌 시 베이스를 따른다.

## 출력
- 1024×1024(정사각), PNG. 캐릭터별 `char_<name>.png`.
- 이 시트(char_ref) = 이후 scene-image가 `-i`로 첨부하는 인물·스타일 단일 소스.

## 파이프라인 위치
원고 → 캐릭터 추출(roster.json) → **character-sheet(아트스타일+정체성 → 인물 시트)** → [[scene-image]](콘티+시트+아트스타일+explainer → 씬) → 씬 레이어 분리 → AE

## 핵심 원칙
- 아트스타일 텍스트는 **모든 이미지 생성 단계에 일관 주입**한다(캐릭터 시트 → 씬 → 레이어). 스타일 단일 소스 = `semoji.md`. **캐릭터 시트가 그 첫 적용 지점.**

## 한국어 규칙
- 가타카나/히라가나/한자 금지
